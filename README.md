# Calculadora Simples

## 📌 Sobre o Projeto

Este projeto é uma calculadora simples desenvolvida utilizando **HTML**, **CSS** e **JavaScript**.  
Ela foi criada com o objetivo de praticar conceitos básicos de desenvolvimento web, manipulação do DOM e lógica de programação.

A calculadora realiza operações matemáticas básicas de forma rápida e intuitiva.

---

## 🚀 Funcionalidades

A calculadora realiza as seguintes operações:

- ➕ Adição
- ➖ Subtração
- ✖️ Multiplicação
- ➗ Divisão

Além disso, possui:

- Interface simples e responsiva
- Atualização dinâmica dos valores
- Botão para limpar o visor
- Exibição do resultado em tempo real

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** → Estrutura da aplicação
- **CSS3** → Estilização da interface
- **JavaScript** → Lógica e funcionalidades da calculadora
